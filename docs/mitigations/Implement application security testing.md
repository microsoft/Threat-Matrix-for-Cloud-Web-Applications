# Implement Application Security Testing

!!! info inline end
    ID: MS-M7005<br>
    MITRE mitigation: [M1016](https://attack.mitre.org/mitigations/M1016/)

Integrate security testing into development workflows including static application security testing (SAST), dynamic application security testing (DAST), and software composition analysis (SCA). These tools help identify vulnerabilities before code reaches production.

## Techniques Addressed by Mitigation

|ID|Name|Use|
|--|----------|-----------|
|[MS-TA7002](../techniques/Application%20vulnerability.md)|Application vulnerability|Integrate static (SAST), dynamic (DAST), and software composition analysis (SCA) into development workflows.|
|[MS-TA7009](../techniques/Application%20exploit%20(RCE).md)|Application exploit (RCE)|Use SAST, DAST, and dependency scanning to identify and remediate RCE risks.|
