# Use Compute Reservations

!!! info inline end
    ID: MS-M7045<br>
    MITRE mitigation: -

Configure autoscaling limits and compute reservations to prevent unlimited resource scaling. Limiting scaling behavior prevents attackers from consuming excessive compute resources for unauthorized purposes.

## Techniques Addressed by Mitigation

|ID|Name|Use|
|--|----------|-----------|
|[MS-TA7031](../techniques/Resource%20hijacking.md)|Resource hijacking|Limit scaling behavior with autoscaling limits.|
