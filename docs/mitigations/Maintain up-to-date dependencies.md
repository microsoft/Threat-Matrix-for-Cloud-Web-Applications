# Maintain Up-to-Date Dependencies

!!! info inline end
    ID: MS-M7004<br>
    MITRE mitigation: [M1051](https://attack.mitre.org/mitigations/M1051/)

Regularly update application code, third-party libraries, frameworks, and dependencies to patch known vulnerabilities. Implement automated dependency scanning and update processes to ensure timely patching.

## Techniques Addressed by Mitigation

|ID|Name|Use|
|--|----------|-----------|
|[MS-TA7002](../techniques/Application%20vulnerability.md)|Application vulnerability|Regularly update third-party libraries, frameworks, and dependencies to patch known vulnerabilities.|
|[MS-TA7009](../techniques/Application%20exploit%20(RCE).md)|Application exploit (RCE)|Patch application code, frameworks, and libraries to eliminate exploitable vulnerabilities.|
