# Image Assurance Policy

!!! info inline end
    ID: MS-M7010<br>
    MITRE mitigation: [M1045](https://attack.mitre.org/mitigations/M1045/)

Ensure that only images that passed the security compliance policies are pushed to registries and deployed to cloud environments. This prevents compromised or vulnerable images from being used in production.
