# Implement Domain Ownership Verification

!!! info inline end
    ID: MS-M7002<br>
    MITRE mitigation: -

Use cloud provider domain verification mechanisms to validate ownership before allowing services to be associated with a domain. This ensures only authorized services can claim and use specific domain names.
