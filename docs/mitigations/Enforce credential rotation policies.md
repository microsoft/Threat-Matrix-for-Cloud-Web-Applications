# Enforce Credential Rotation Policies

!!! info inline end
    ID: MS-M7019<br>
    MITRE mitigation: -

Establish and enforce policies for regular rotation of deployment credentials, API keys, tokens, and other secrets. Regular rotation limits the window of opportunity for attackers to use compromised credentials.

## Techniques Addressed by Mitigation

|ID|Name|Use|
|--|----------|-----------|
|[MS-TA7007](../techniques/Using%20deployment%20credentials.md)|Using deployment credentials|Regularly rotate deployment credentials such as personal access tokens, publish profiles, and service principal secrets.|
