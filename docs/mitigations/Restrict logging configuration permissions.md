# Restrict Logging Configuration Permissions

!!! info inline end
    ID: MS-M7029<br>
    MITRE mitigation: [M1035](https://attack.mitre.org/mitigations/M1035/)

Use policies to prevent unauthorized modification or deletion of logging settings across cloud platforms. Protecting logging configurations ensures audit trails remain intact for security monitoring and incident response.
