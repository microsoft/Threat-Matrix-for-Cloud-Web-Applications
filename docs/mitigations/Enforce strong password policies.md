# Enforce Strong Password Policies

!!! info inline end
    ID: MS-M7031<br>
    MITRE mitigation: [M1027](https://attack.mitre.org/mitigations/M1027/)

Require complex passwords that are resistant to brute-force and dictionary attacks. Password policies should enforce minimum length, complexity requirements, and prevent use of common or previously breached passwords.

|ID|Name|Use|
|--|----------|-----------|
