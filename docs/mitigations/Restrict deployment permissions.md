# Restrict Deployment Permissions

!!! info inline end
    ID: MS-M7042<br>
    MITRE mitigation: -

Limit who can deploy code or modify application content to authorized personnel only. Restricting deployment permissions prevents unauthorized changes that could alter application behavior or appearance.
