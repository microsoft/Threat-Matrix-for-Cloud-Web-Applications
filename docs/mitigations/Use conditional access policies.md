# Use Conditional Access Policies

!!! info inline end
    ID: MS-M7018<br>
    MITRE mitigation: -

Implement conditional access policies that evaluate contextual factors before granting access to cloud resources. These policies can consider IP address, device compliance, user risk level, location, and time of day to make dynamic access decisions.
