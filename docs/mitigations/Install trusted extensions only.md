# Install Trusted Extensions Only

!!! info inline end
    ID: MS-M7023<br>
    MITRE mitigation: [M1033](https://attack.mitre.org/mitigations/M1033/)

Define and enforce a list of approved extensions that can be installed on cloud application services. Only allow installation of extensions from trusted sources that have been vetted for security.

## Techniques Addressed by Mitigation

|ID|Name|Use|
|--|----------|-----------|
|[MS-TA7012](../techniques/Site%20extensions.md)|Site extensions|Define and enforce a list of approved extensions that can be installed on App Service instances.|
