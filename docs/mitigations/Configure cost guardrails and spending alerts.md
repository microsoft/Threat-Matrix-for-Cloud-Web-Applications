# Configure Cost Guardrails and Spending Alerts

!!! info inline end
    ID: MS-M7043<br>
    MITRE mitigation: -

Set budget limits with automatic alerts and optional service shutdowns when cost thresholds are exceeded. Cost guardrails protect against financial damage from denial-of-wallet attacks or runaway resource consumption.
