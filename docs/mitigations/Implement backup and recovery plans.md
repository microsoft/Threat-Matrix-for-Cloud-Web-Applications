# Implement Backup and Recovery Plans

!!! info inline end
    ID: MS-M7041<br>
    MITRE mitigation: [M1053](https://attack.mitre.org/mitigations/M1053/)

Regularly back up critical data to separate, protected locations and test restoration procedures. Reliable backups enable recovery from data destruction or corruption incidents.
